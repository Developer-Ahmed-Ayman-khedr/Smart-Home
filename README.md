# Smart-Home
A smart Home using ATMEGA32.
It was made using Embedded C.
It includes:
1. Login system: that holds data in the internal EEPROM, and contains the password of the admin and 4 users.
2. Temperature check and Control of Motor for cooling.
3. Control of Servo using Timer1 to open the door for the users.
4. Ultrasonic using Timer0 and External Interrupt.
5. Connection for the system using UART Protocol for the admin and LCD & Keypad for the users.
6. It was designed on Proteus.
